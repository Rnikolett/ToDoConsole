# A simple ToDoConsole Application for Learning C#

It's a simple C# console application for managing tasks. It allows users to create, view, and delete tasks, set due dates and priorities.

## Features
- Add new tasks
- Add descriptions and due dates
- Set task priority (Low, Medium, High)
- View all tasks in the console
- Delete tasks
- Edit tasks (in progress)
- Save task data locally in JSON format

## Tech Stack
- C#
- .NET
- Console application
